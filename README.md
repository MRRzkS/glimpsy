# Glimpsy

Glimpsy is a focused opportunity intelligence workspace for freelance web developers. It normalizes project opportunities from multiple freelance platforms so developers can evaluate requirements, timelines, budgets, and fit without jumping between marketplaces.

## Product principles

- **Signal over volume** — prioritize opportunities worth evaluating, not endless listings.
- **One normalized model** — platform-specific payloads stay behind source adapters.
- **Fast scanning** — budget, timeline, stack, source, and project intent should be obvious at a glance.
- **Calm premium interface** — information density without visual noise.
- **Human-readable engineering** — explicit naming, small responsibilities, and comments only where context matters.

## Initial scope

The first milestone includes a marketing landing page and a working opportunity feed powered by representative mock data. Source integrations, persistence, authentication, and matching intelligence will be layered onto the same domain model next.
